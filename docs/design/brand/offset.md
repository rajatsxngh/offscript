# Offscript / Offset

Selected concept C. The approved [reference board](offset-reference.png) pairs a cobalt symbol with a lowercase navy wordmark.

The symbol uses two opposing solid curves and an open diagonal passage. Keep the two pieces together and preserve their spacing; the mark needs no gradients or animation to read. The primary blue is `#0866ff` and wordmark ink is `#10203c`.

The shared React artwork lives in `src/components/brand-logo.tsx`. The standalone mark is available as `/brand/offscript-offset.svg`; the cool-white app icon is `/brand/offscript-app-icon.svg`. The same icon is used by Next's file-based browser icon route. These are clean SVG interpretations of the approved concept, not bitmap crops.

The full lockup appears in the desktop header, library and loading screen. The settings emblem and assistant avatar use the symbol. At widths of 600 px or below, the header uses only the symbol while its home button retains an accessible label; the library keeps the full name. Wordmark typography uses Avenir Next where available and the app's system sans fallback elsewhere.
